## Current research

**Few-Shot Learning for Breast Histopathological Image Classification Using Meta-Learning** · *In progress*

Cross-domain few-shot learning (CD-FSL) research using a planned multi-scale convolutional feature extractor and multi-head self-attention, adapted with MAML (inner-loop updates on support sets and outer-loop optimisation on query sets). The planned PyTorch experiments use 5-, 10- and 20-shot N-way episodes.

- **Datasets:** BreaKHis as the source domain (40×–400×; benign/malignant) and BACH as the target domain (four classes, 100 images per class).
- **Work completed:** abstract, Review 2 report and a Review 3 literature survey covering 10 papers, including Meta-CDMTransNet, MetaMed, DCPN, UNI, MIL-Adapter, PANet, STMLAN, Meta Channel Masking and Pani et al.'s vision–text fusion work.
- **Separate supervisor task:** recreate Pani et al. (IEEE CBMS 2025) and investigate its failure points; this is separate from the main M.Tech project.

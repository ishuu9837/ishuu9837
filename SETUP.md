# Install this GitHub profile README

1. Create or open the public repository named **`ishuu9837`** (the repository name must match your GitHub username).
2. Copy the contents of this folder into the repository root, including `.github/`, `assets/`, `data/` and `scripts/`.
3. Keep the default branch named `main` and enable GitHub Actions. The included workflow refreshes the live data and animated SVGs every six hours; you can also start **Refresh plates** manually from the Actions tab.
4. The workflow commits refreshed assets back to this repository, so allow Actions to write repository contents. No token is needed for the public REST profile data; the contribution workflow uses the GitHub Actions token and keeps the current cache if a refresh is unavailable.

The original copper/sage theme, dark/light variants, pixel-art scene, terminal card and animated contribution graphics are retained. The initial activity data was seeded from the public contribution calendar visible on GitHub on 10 October 2026.
